# Estructura de Datos Unidad 1 Protocolo Colaborativo

Actividad grupal sobre arreglos y matrices desarrollada sin Java. El repositorio contiene implementaciones equivalentes en Python, C# y TypeScript.

## Integrantes

| Integrante | Lenguaje y aporte |
| --- | --- |
| Carlos Andres Nuñez Vargas | Python: arreglos, matrices y pruebas. |
| Pendiente | C#: arreglos y matrices. |
| Pendiente | TypeScript: arreglos y matrices. |

Reemplacen los campos pendientes antes de entregar y agreguen a todos los integrantes como colaboradores del repositorio público.

## Estructura

```text
python/       Implementación ejecutable en Python
csharp/       Implementación ejecutable en C# .NET
typescript/   Implementación ejecutable en TypeScript
docs/         Comparativa y nota para el tutor
```

## Cómo ejecutar

### Python

```powershell
cd python
python main.py
```

### C#

```powershell
cd csharp
dotnet run
```

### TypeScript

```powershell
cd typescript
npm install
npm run start
```

Cada implementación demuestra: creación de un arreglo de 10 enteros aleatorios, recorridos `for` y `for-each`, modificación independiente sobre copias, búsqueda lineal, matriz 3x3, recorrido por columnas, suma, intercambio de filas y matriz irregular.
